ONUR'UN SİTESİ - GITHUB PAGES KURULUMU

DOSYALAR:
- index.html
- style.css
- app.js
- README.txt

GITHUB'A YÜKLEME:
1. ZIP dosyasını bilgisayarında çıkar.
2. İçindeki index.html, style.css ve app.js dosyalarını GitHub Pages repository'ne yükle.
3. GitHub > Settings > Pages bölümüne gir.
4. Source olarak Deploy from a branch seç.
5. Branch: main
6. Folder: / (root)
7. Save'e bas.

MÜZİK:
- Kendi müzik dosyanı "music.mp3" adıyla aynı klasöre koy.
- GitHub'a diğer dosyalarla birlikte yükle.
- Tarayıcılar otomatik müzik başlatmayı engellediği için kullanıcı Müzik düğmesine basmalı.

GİRİŞ / KAYIT:
- Arayüz hazır.
- Gerçek kullanıcı hesabı ve şifre sistemi henüz bağlı değildir.
- GitHub Pages statik bir hosting olduğu için Supabase/Firebase gibi güvenli bir kimlik doğrulama servisi gerekir.
- Şifreleri JavaScript veya localStorage içinde saklama.
